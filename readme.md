# pattern analysis

## 1. daten transformieren
starte transform_data.py, welches die daten in /data/ in ein auswertbares format transformiert und in /data/transformed
speichert

## 2. sequenzanalyse
starte detect_codes_within.py, welches die daten in /data/transformed/ auf die gesuchten sequenzen analysiert und die
ergebnisse in /data/processed/sequence_analysis.csv speichert
